# Sangam Sedai — Portfolio

A modern, professional portfolio website built with vanilla HTML, CSS, and JavaScript.

**Live:** [sangamsedai.com.np](https://sangamsedai.com.np)

## Features

- Dark/Light theme toggle with persistence
- Scroll-progress indicator
- Sticky glassmorphism navigation with active-section tracking
- Hero section with typing animation
- Tabbed About section (Skills, Experience, Education)
- Animated skill bars triggered on scroll
- Animated stats counters (projects, skills, experience, clients)
- Services and Project cards with hover effects
- Tech-stack tags on project cards
- Contact form with icon inputs, integrated with Google Sheets
- Scroll-reveal fade-in animations
- Back-to-top button
- Fully responsive (mobile-first)
- SEO-optimized with Open Graph tags

## Tech Stack

HTML, CSS (Custom Properties), JavaScript (IntersectionObserver), Font Awesome, Google Fonts
